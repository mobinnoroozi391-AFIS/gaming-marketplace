# Gaming Marketplace

یک رابط کاربری مدرن برای مارکت‌پلیس خرید و فروش آیتم، جم، اکانت و سرویس‌های گیمینگ.

## Features

- Modern Gaming Marketplace UI
- RTL / Persian interface
- Product categories
- Product filtering
- Product purchase modal
- User dashboard
- Order tracking
- Internal chat UI
- Support ticket UI
- Responsive design
- Mobile friendly
- Fast and lightweight
- Pure HTML / CSS / JavaScript
- No external dependencies
